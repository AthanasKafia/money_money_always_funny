Connect Your Free Google Firebase Database (For GitHub Hosting)

Right now inside this preview, real-time cloud sync works automatically! When you host index.html on GitHub Pages, you can create a 100% free Firebase Spark project (0€/month forever) and paste its firebaseConfig below once:

  1. Go to console.firebase.google.com → Create a project (Free).
  2. Enable Authentication → Sign-in method → Turn on Anonymous.
  3. Enable Firestore Database → Create database → Start in test mode (or allow read/write).
  4. Go to Project Settings (gear icon) → Add Web App (</>) → Copy the firebaseConfig object or JSON and paste it below:

How to Host on GitHub & Connect Y in 1 Click

  1. Upload this single file as index.html to your GitHub repository and enable Settings → Pages.
  2. Open your GitHub Pages link, paste your Firebase config above, and click Save & Connect Cloud.
  3. Click "Copy Magic Setup Link for Y" above and send it to Y on WhatsApp! When Y opens that link once, Y's phone/laptop automatically connects to the exact same live database!
